# Privacy Policy

Last updated: November 25, 2026

Life Manager ("the app") is a private application used by a single person, its developer, to access their own Google account data.

## Data the app accesses
With the developer's explicit consent, the app accesses the developer's own Gmail messages and Google Calendar events through Google APIs.

## How the data is used
The data is used only to provide the app's features to the developer. It is not shared with any third party, sold, used for advertising or used to train any generalized AI or machine learning model.

## Storage
Authorization tokens are stored on the developer's own device. Email and calendar content is not copied to any public server.

## Google API Services User Data Policy
The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access
Access can be revoked at any time at https://myaccount.google.com/permissions.
